# SEAM 개편

SEAM 개편은 세 단계로 진행한다: **기획 다듬기 → UI 정리(시안 HTML) → 파트별 적용**.

## 기준 우선순위

1. 시안 HTML: [ui-mockup-v2.html](ui-mockup-v2.html)
2. 파트 설계 문서: 이 폴더의 `NN-이름.md`
3. 현행 코드: 이미 있는 기능의 사실 기준

`docs/history/`는 참고 기록이다. 근거로 쓰기 전에 위 기준과 충돌하지 않는지 먼저 확인한다.
