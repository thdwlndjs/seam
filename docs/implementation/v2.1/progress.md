## Phase 2 — 완료 기준 연결 (`plan.md` Phase 2)

- 충족: 산출물 항목+출처 링크, `DERIVED_FROM`, 문서가 자동으로 확인 필요가 되지 않음, 인용 불일치·계약 위반·판정 실패는 `runs`에만 기록(재시도 3회, `reprocess`, 관리자 요약 줄), 캐시 적중 시 LLM 재호출 없음, 합의 인용 없는 `agreed` 금지, 사람 수정 보호.
- 합성 데이터+실제 LLM으로 `alternative`·`resolving`·`supersede`·자동 반영·되돌리기 확인.
- **미충족:** 실데이터 복사본에서는 `alternative`·`resolving`·`supersede` 사례 0건(판정 호출 일일 한도). 반영 대기 부분과 인용 불일치 재시도 3건 남음.
- 알려진 문제: 문서 인용 불일치율이 큼(마크다운 표시 차이는 허용하도록 고침), 산출물 제목이 같은 페이지 제목이면 `(ID꼬리)`가 붙음.

### Phase 4 — 원인 메모(제목 중복)

- 부분 경로는 `루트 > … > 페이지 제목 > 부분 제목`이다. Phase 2의 산출물 제목이 경로 **첫 마디(루트 이름)**를 써서 모든 산출물이 같은 제목이었다. 마지막 마디로 고쳤고, 다시 해석할 때 예전 제목도 바로잡는다(사람이 고친 것은 건드리지 않음).
- 같은 제목이 그래도 겹치면 출처 표기는 `윗 경로 > 제목`, 그다음 `#ID꼬리`로 구분한다.
