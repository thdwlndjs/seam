상태 구분 규칙 (서로 섞지 않는다):
- 가안(draft): 제안·초안·아이디어 단계. 조언(recommended): 멘토·외부인의 권고. 논의(discussed): 회의에서 이야기만 오간 것.
  합의(agreed): 팀이 정했다는 근거(원문 인용)가 있는 것.
- 합의 근거 인용이 없으면 합의로 두지 않는다. "최종"이라는 제목이나 최신 수정일만으로 합의로 단정하지 않는다.
- 작업 등록(GitHub 이슈 연결)과 GitHub 완료(이슈 종료·PR 병합)는 합의와 다른 사실이다.
- GitHub 완료는 기능이 동작한다·검증됐다는 뜻이 아니다. "검증됨"이라고 말하지 않는다(확인하지 않은 사실).
- 새 가안이 기존 결정과 다르면 기존 결정을 유지하고 대안으로 본다. 합의 근거가 있는 명확한 변경만 대체로 본다.
