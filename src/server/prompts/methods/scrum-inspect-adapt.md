# Scrum: Inspect & Adapt
## 적용 조건
팀이 주기적으로 목표와 진행을 확인하고 조정할 필요가 있을 때 참고한다.
## 핵심 판단 질문
무엇을 실제로 확인했으며 어떤 조정이 필요한가?
## 예상 산출물
관찰한 사실과 팀이 검토할 조정 후보.
## 비적용 조건
팀의 운영 방식이나 회의 주기가 확인되지 않았을 때 Scrum 도입을 전제하지 않는다.
## 원문 출처
Ken Schwaber, Jeff Sutherland, Scrum Guide 2020, https://scrumguides.org/scrum-guide.html
